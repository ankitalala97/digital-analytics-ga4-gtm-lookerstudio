# Digital Analytics Implementation Project

## Project Overview
This project was completed as part of an academic team project focused on a travel-themed website. The website was designed to share travel stories, destination information, photos, tips, and appointment-based interaction features for users interested in travel planning.

My contribution focused on the digital analytics and reporting side of the project. I worked on GA4 event tracking, Google Tag Manager setup, user behavior analysis, Looker Studio dashboard/reporting, KPI planning, business goal mapping, and analytics documentation.

## My Contribution
My main responsibilities included:

- Setting up GA4 event tracking for key website interactions
- Configuring Google Tag Manager to support event measurement
- Creating analytics events for user engagement tracking
- Building Looker Studio dashboards/reports to visualize website performance
- Supporting user behavior analysis using analytics data
- Mapping business goals to measurable website actions
- Documenting the analytics setup and measurement approach

## Business Goals
The project focused on four key business goals:

- Grow website audience and reach
- Increase user engagement with travel content
- Build a loyal subscriber base
- Strengthen brand awareness and trust

## Tracking and Measurement Setup
The analytics setup included measurable goals and event tracking for key website interactions, including:

- `appointments_click` — Track when users click the Appointments button to measure interest in travel-related queries
- `instagram_click` — Track outbound clicks to the Instagram page to measure social engagement
- `subscribe_click` — Track Subscribe button clicks to measure newsletter or sign-up interest
- `scroll_depth` — Measure how far users scroll to understand content engagement
- Microsoft Clarity — Support user behavior analysis through heatmaps and session insights
- GA4 Configuration Tag — Activate GA4 tracking across website pages

## Reporting and Analysis
I created Looker Studio dashboards/reports to help visualize website performance and user engagement trends. The reporting focused on understanding how users interacted with the website and whether key business goals were being supported through measurable actions.
